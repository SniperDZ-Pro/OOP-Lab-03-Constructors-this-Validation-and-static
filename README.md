# OOP Lab 03: Constructors, `this`, Validation and `static`

Welcome to Lab 03. After encapsulating the object's state in Lab 02, this session completes the protection by ensuring an object is never born or modified in an invalid state—using constructors, the `this` keyword, validation, and the `static` modifier in Java and the Eclipse IDE.

## Objective
Understand and apply constructors (default, parameterized, copy, and chained) to initialize objects correctly at creation time. Use `this` to distinguish attributes from parameters and to reuse constructor logic. Enforce data integrity through validation inside setters and constructors, and use `static` attributes and methods to share data at the class level. You will also learn how to pass objects between methods.

## Contents
- `Book.java`: The fully protected class with constructors, validated setters, and a static counter.
- `MainApp.java`: The main execution program testing validation, constructors, and static behavior.
- **Individual Tasks:** 8 hands-on exercises to add validated attributes, chain constructors, pass objects, and reset a static counter.
